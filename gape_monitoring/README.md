`gape_monitoring`

### DESCRIPTION

This directory contains guides and code for implementing, and analyzing, gape monitoring data collected using an Adafruit RP2040 Adalogger Feather and the Adafruit TLV493D three-axis magnetometer, via small neodymium magnet(s) attached to the leading edge of the shell. At some point in the future, these guides/code will also handle the Adafruit DS3231 Precision RTC to allow for date/time logging. All components are STEMMA-QT compatible (i.e. uses a cable instead of requiring soldering).
